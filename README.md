# moex-invest

Скрипт для разового снапшота котировок облигаций через [T-Bank Invest API](https://developer.tbank.ru/invest/api).
По всем доступным для торговли облигациям тянет цены, купоны, считает доходности и складывает в Excel и SQLite.

---

## Что попадает в таблицу

| Колонка | Источник / расчёт |
|---|---|
| ISIN, Наименование, FIGI | `InstrumentsService/Bonds` |
| Дата погашения, Номинал, НКД, Валюты, Купонов в год | то же |
| Уровень риска | `riskLevel` → «Низкий / Средний / Высокий» |
| Амортизация, Бессрочные, Плавающий купон | флаги бумаги + детектор купонов |
| Цена, % от номинала | `MarketDataService/GetLastPrices` (Quotation как % номинала) |
| Купонная доходность, % | следующий известный купон, аннуализован: `coupon × купонов_в_году / номинал × 100` |
| Текущая купонная доходность, % | `купонная_доходность × 100 / цена_%` |
| Дата, к которой рассчитана доходность | дата погашения / дата последнего известного купона / — |
| Тип даты | «Погашение» / «Последний известный купон» / «Плавающий купон» |
| Доходность, % | YTM, YTP или формула `CBR_RATE + X` (см. ниже) |
| Лет до даты | разница между датой расчёта и текущей |

## Получение токена T-Bank Invest

1. Зайти на [t-bank.ru](https://t-bank.ru) → раздел **«Инвестиции» → «Настройки» → «Токены Tinkoff Invest API»**.
2. Создать токен с правами **«Только чтение»** (торговля скрипту не нужна).
3. Скопировать строку (после закрытия окна не покажется повторно).
4. Скопировать шаблон и вставить токен:

   ```cmd
   copy .env.example .env
   ```

   В `.env`:
   ```
   TBANK_TOKEN=t.AAAAAAAAA...
   ```

`.env` уже в `.gitignore`, в репозиторий не попадёт.

## Запуск

Сначала на 30 бумагах — проверить, что всё работает:

```cmd
python bonds_snapshot.py --limit 30
```

Полный прогон (~1500 облигаций):

```cmd
python bonds_snapshot.py
```

**Сколько идёт.** Метод `GetBondCoupons` зовётся по одной облигации, лимит API — около 300 запросов в минуту. Плюс сетевой round-trip. Итого на холодном прогоне ~5–7 минут.

```sql
SELECT snapshot_ts, last_price_pct, yield_pct
FROM snapshots
WHERE isin = 'RU000A105SP3'
```

## Логика расчёта доходности

Для каждой облигации скрипт выбирает один из трёх сценариев:

| Сценарий | Когда срабатывает | «Дата» | «Доходность, %» |
|---|---|---|---|
| **Погашение** | бумага с фиксированным купоном до конца | `maturity_date` | YTM (метод Ньютона → bisection-fallback) |
| **Последний известный купон** | в API часть купонов известна, дальше нули | дата последнего ненулевого купона | доходность к этой дате (формула YTM, но «погашение» = оферта/пересмотр) |
| **Плавающий купон** | все купоны помечены `COUPON_TYPE_FLOATING` | — | `CBR_RATE + X.XX`, где X = текущая_ставка_купона − ключевая_ставка_ЦБ |

**YTM / YTP** — численное решение уравнения:
```
грязная_цена = Σ CF_i / (1 + y)^t_i  +  выплата_номинала / (1 + y)^T
```
где грязная цена = `цена + НКД`, CF_i — купоны, T — дата конца расчёта.

### Ключевая ставка ЦБ

Используется только для разложения купона флоатера в формулу. Задаётся в [`config.py`](config.py):

```python
CBR_KEY_RATE = 14.5  # обновлять вручную после заседаний ЦБ
```

После изменения ставки ЦБ — поменять число и перезапустить снапшот.

## Ограничения

- **Оферта неотличима от пересмотра купона.** API не отдаёт явный флаг оферты, паттерн «известные купоны → нули» идентичен для обоих случаев. Оба идут как «Последний известный купон». Для точного различия нужен внешний источник (MOEX ISS, rusbonds).
- **Амортизация.** YTM считается с полным номиналом на дату погашения. Для амортизируемых бумаг (`Амортизация = да`) реальный YTM может слегка отличаться.
- **Флоатеры с базой не CBR.** Скрипт предполагает, что флоатер привязан к ключевой ставке ЦБ. Если база другая (RUONIA — ОФЗ-ПК, ROISfix, инфляция), «спред» в формуле будет смещён.
- **Замещающие / золотые облигации.** Бумаги вроде `RU000A106XD7` (Селигдар GOLD02) имеют плавающий номинал, привязанный к валюте/золоту — YTM по ним не учитывает динамику базового актива.
- **Кредитный рейтинг.** В T-Bank API его нет, в таблице не выводится.

## Веб-дашборд (Streamlit + AgGrid)

Поверх SQLite — интерактивный дашборд: Excel-стайл фильтры в заголовках столбцов, динамический построитель графиков, история по конкретной облигации.

```cmd
streamlit run app.py
```

Откроется `http://localhost:8501`. Что в нём есть:

- **Снапшот** — выпадающий список всех сохранённых снапшотов (в боковой панели).
- **Таблица с фильтрами в заголовках столбцов** (AgGrid):
  - Кликаете на значок «☰» справа от названия столбца → выпадающее окно с условиями: содержит / равно / больше / меньше / между. Аналог автофильтра в Excel.
  - Сортировка кликом по заголовку (Shift+клик — мультиколоночная).
  - Числовые столбцы форматируются до 2 знаков и фильтруются как числа; текстовые/категориальные — как текст.
  - Под таблицей: «Отфильтровано: N из M» и кнопка скачать CSV.
- **Динамический график строится по тому, что осталось в таблице** после фильтров:
  - Тип: Scatter / Histogram / Box / Bar.
  - X — любая колонка, Y — любая числовая.
  - Цвет — любая колонка (например, «Тип даты» — видно кластеры).
  - Размер точки (Scatter) — любая числовая.
- **История по облигации** — выберите ISIN из отфильтрованного списка → линия цены / YTM / текущей купонной доходности по всем снапшотам. Появляется только после второго прогона `bonds_snapshot.py`.
- **Кнопка «Получить актуальные данные»** — в боковой панели. Запускает `bonds_snapshot.py` в фоне; прогресс отображается в реальном времени (`coupons — 234/1518`). После завершения данные автоматически перечитываются. Параллельные запуски заблокированы — пока идёт один, кнопка скрыта.

### Доступ с других устройств в локальной сети

```cmd
streamlit run app.py --server.address 0.0.0.0
```
Откройте `http://<ip-вашей-машины>:8501` с телефона или другого компьютера в той же сети.

## Структура проекта

```
bonds_snapshot.py    # точка входа снапшота: catalog → prices → coupons → запись
tbank_client.py      # клиент T-Bank REST API (requests), dataclass Bond / Coupon
ytm.py               # расчёты: YTM/YTP, детект оферты, аннуализированный купон
storage.py           # запись в Excel (openpyxl) и SQLite, схема таблицы snapshots
config.py            # пути, batch-размеры, ключевая ставка ЦБ
app.py               # Streamlit-дашборд: фильтры + динамические графики + история
requirements.txt
.env.example         # шаблон, реальный токен кладётся в .env
```

## Дальнейшие идеи

- Кэш купонов в SQLite с TTL — второй и последующие запуски за сутки будут идти секунды вместо минут.
- Параллелизация `GetBondCoupons` через `ThreadPoolExecutor` — холодный прогон в 2–3× быстрее.
- Поддержка watchlist через `--isins` (только указанные ISIN, без полного каталога).
- Алерты по порогам YTM / цены (Telegram, email).
